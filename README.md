# ImprovMX Studio

**Управление почтовыми доменами и алиасами в едином интерфейсе.**

ImprovMX Studio — независимое настольное приложение для управления почтовой переадресацией через **ImprovMX API v3**.

Проект объединяет управление доменами, создание и настройку почтовых алиасов, массовые операции и персонализацию интерфейса в одном приложении.

В основе — Python и PySide6, с акцентом на современный дизайн, удобную навигацию и повседневное администрирование почтовой инфраструктуры.

---

## Возможности

### Управление доменами
- Подключение и удаление доменов через ImprovMX API.
- Просмотр подключённых доменов и их состояния.
- Поиск по списку доменов.
- Настройка адресов уведомлений и параметров Whitelabel.

### Почтовые алиасы
- Создание, редактирование и удаление алиасов.
- Управление адресами переадресации.
- Просмотр и поиск существующих алиасов.
- Быстрое переключение между доменами.

### Массовые операции
- Интерфейс пакетного создания алиасов.
- Массовое изменение и удаление записей.
- Ввод данных в CSV-подобном формате.
- Просмотр результатов выполнения операций.

### Персонализация
- 11 встроенных цветовых тем.
- Интерфейс в стиле Acrylic / Glass.
- Настраиваемая прозрачность окна.
- Система локализации с поддержкой языковых пакетов.
- Настройка API-токена непосредственно в приложении.

## Интерфейс

ImprovMX Studio использует собственную визуальную систему с полупрозрачными панелями, мягкими цветовыми переходами и адаптируемыми элементами управления.

Основные разделы приложения:

| Раздел | Назначение |
|---|---|
| Domains | Управление подключёнными доменами |
| Aliases | Создание и редактирование переадресаций |
| Bulk | Массовые операции с алиасами |
| Settings | Настройка подключения и оформления |

## Принцип работы

Приложение взаимодействует с ImprovMX посредством официального REST API.

Все операции управления доменами и алиасами выполняются через API с использованием персонального токена авторизации.

ImprovMX Studio не является самостоятельным почтовым сервером и не заменяет инфраструктуру доставки электронной почты.

Для работы необходима учётная запись ImprovMX с действующим API-токеном. Доступные возможности и ограничения определяются используемым тарифом сервиса.

## О проекте

ImprovMX Studio создан для тех, кто использует собственные домены и предпочитает управлять почтовой переадресацией через отдельное настольное приложение.

Основная идея проекта — объединить необходимые инструменты администрирования в одном интерфейсе, сохранив прямую интеграцию с ImprovMX.

**Независимый проект. Не является официальным приложением ImprovMX.**
